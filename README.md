# おうちどうが

保護者が選んだYouTube動画だけを見られる、子供向けの動画プレーヤーです。
最初に再生ボタンを押してから60分たつと「チャレンジタイム」になり、3つのチャレンジカードすべてで家族の確認（パスワード）を済ませると、また見られるようになります。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `videos.js` | **ここだけ編集すればOK**。動画リスト・お手伝い・時間・暗証番号の設定 |
| `index.html` / `style.css` / `app.js` | 画面と動作（通常は編集不要） |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加したときのアプリ名・アイコン |

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（例：`ouchi-douga`、Public）
2. このフォルダの中身をすべてアップロード（`Add file` → `Upload files`）
3. `Settings` → `Pages` → `Build and deployment` の Source を `Deploy from a branch`、Branch を `main` / `/(root)` にして `Save`
4. 数分後、`https://<GitHubユーザー名>.github.io/ouchi-douga/` で開けるようになります

※ 無料プランの GitHub Pages は Public リポジトリが前提です。中身は動画リストのみです。

## 動画を追加・変更する

`videos.js` の `videos` に1行ずつ追加します。URLはYouTubeのものをそのまま貼り付けられます。

```js
{ url: "https://www.youtube.com/watch?v=XXXXXXXXXXX", title: "表示する名前", lang: "ja" },
```

- `lang` は `"ja"`（にほんご）/ `"en"`（えいご）/ それ以外（そのた）。2種類以上あるとリスト上部に絞り込みボタンが出ます
- GitHub上で `videos.js` を編集して `Commit changes` すれば、数分でタブレットにも反映されます（反映されない場合はページを再読み込み）
- 投稿者が埋め込みを禁止している動画は再生できません。その場合「この どうがは ここでは みられません」と表示され、リストで薄く表示されます

## 主な設定（videos.js）

| 項目 | 初期値 | 内容 |
|---|---|---|
| `limitMinutes` | 60 | 最初に再生した時点から、チャレンジタイムまでの分数 |
| `warnMinutes` | 5 | 残り何分でお知らせを出すか（0で無効） |
| `parentPin` | `"1026"` | 家族用パスワード。チャレンジカードの確認とおうちの人メニューで入力が必要。`""` でパスワードなし |
| `choresPerBreak` | 3 | 1回に出すチャレンジカードの枚数 |
| `chores` | 18種類 | チャレンジ（お手伝い・遊び・休憩など）の候補。この中からランダムに選ばれます |

## 動きの仕様

- 再生ボタンを押した時点から計測を開始し、一時停止中も時間は進みます
- 時間になると再生を止め、全画面表示も解除してチャレンジタイムに切り替わります
- 各カードの「おうちの人の かくにん」を押すとパスワード入力が出て、正しく入れると「できた！」のスタンプが付きます。すべて付くと「どうがを みる」ボタンが出ます
- ロック解除後は計測がリセットされ、次に再生ボタンを押した時点からまた60分です
- 状態はタブレットのブラウザに保存されるため、再読み込みやアプリの再起動でもリセットされません
- 動画の上は透明なカバーで覆っており、YouTubeのロゴやタイトルを押してYouTubeへ移動することはできません

## おうちの人メニュー

画面左上のアプリ名を **3秒長押し** すると開きます。

- タイマーをリセット（すぐ見られる状態にする）
- 今すぐチャレンジタイムにする（動作確認用）

パスワードは `videos.js` の `parentPin` で変更できます。

## Androidタブレットでの設定

1. **ホーム画面に追加**：Chromeでページを開き、メニュー（︙）→「ホーム画面に追加」。アイコンから開くと全画面で表示されます
2. **アプリ固定**：設定 → セキュリティ（またはセキュリティとプライバシー）→「アプリ固定」をオン。おうちどうがを開いた状態で履歴ボタンからアプリのアイコンを押し「固定」を選ぶと、ほかのアプリに移動できなくなります（解除には端末の画面ロックを入力）
3. **YouTubeアプリの制限**：ファミリーリンクを使う場合は、子供のアカウントで YouTube アプリと Chrome 以外のブラウザをブロックしておくと確実です

## ねるまえボタン（おやすみタイム）

画面右上の「🌙 ねるまえ」を押すと、動画が止まって「おやすみ タイム」の画面になります。
「おうちの人の かいじょ」を押してパスワード（`parentPin`）を入れると解除され、再生中だった場合は続きから再生されます。
解除後の60分のカウントは、次に再生した時点からやり直しになります（チャレンジタイム中だった場合は、チャレンジ画面に戻ります）。

## YouTube の表示を隠すカバー

一時停止中・動画の読み込み前・本編開始から約3.5秒間・動画の終了時は、動画の上をサムネイル画像で覆い、YouTube のタイトル、停止ボタン、リンク、関連動画、ロゴを見えないようにしています。
広告が流れている間はカバーを外し、右下のスキップボタンだけ押せるようにしています。
